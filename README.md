# Nijoow Portfolio

프론트엔드 작업물과 프로젝트 상세 과정을 정리한 개인 포트폴리오 사이트입니다.

[포트폴리오 보기](https://nijoow-portfolio.vercel.app/)

## 주요 기능

- 홈 파티클 `nijoow` 시그니처 인터랙션
- 프로젝트 카테고리 필터 및 상세 소개 페이지
- Spotify 및 GitHub 활동 내역 표시
- 이메일 문의 폼

## 기술 스택

- Next.js App Router, React, TypeScript
- Tailwind CSS, Framer Motion
- Three.js, React Three Fiber, Drei
- TanStack Query, nuqs, React Hook Form, Zod
- Vercel Analytics, Speed Insights
- Vitest, React Testing Library
