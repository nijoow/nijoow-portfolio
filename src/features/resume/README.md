# 이력 페이지

- 경로: `/resume`
- 내용: 소개, 경력·프로젝트, 학력
- 프로젝트에서 Works 상세로 이동하고 돌아올 때 위치·포커스 복원
- 검색엔진 색인·sitemap에서 제외
- 공개 연락처는 이메일·GitHub만 사용

## 데이터

- `data/generalResume.json`: 별도 resume 저장소의 일반 이력서를 바탕으로 편집한 공개 데이터
- 회사별 제출본과 비공개 연락처는 포함하지 않음
- `node scripts/export-resume-content.mjs [데이터 디렉터리]`: 원본에서 공개 필드 추출
- 내보내기는 사이트 JSON을 덮어쓰므로 기존 문구와 결과를 비교한 뒤 반영
- 프로젝트 추가 시 스크립트의 이름·라우트 매핑도 수정
- 배포 빌드는 별도 resume 저장소에 접근하지 않음
