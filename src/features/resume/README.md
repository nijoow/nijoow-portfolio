# 독립 이력 페이지

`/resume`은 기존 홈·Works·Contact와 별개인 추가 페이지다. 기존 내비게이션과 페이지는 수정하지 않는다. 검토 단계에서는 sitemap에 추가하지 않고 noindex로 제공한다.

## 구성

- 기존 파티클 로고를 재사용한다. 이 페이지에서는 전체 화면 인트로를 기다리지 않고 본문을 읽을 수 있다.
- 범용 이력서의 소개 두 문단, 공개 경력 두 묶음, 실무 프로젝트 9개와 업무 항목 24개, 학력을 표시한다.
- 각 프로젝트를 기존 상세 라우트에 연결한다. 브라우저 뒤로가기 시 읽던 위치와 링크 포커스를 복원한다.
- 경력·업무는 기본으로 펼치고, 긴 자기소개서 세 항목은 하단에서 선택해 읽는다.
- 데스크톱은 기간과 경력 본문을 나란히, 모바일은 한 열로 표시한다. 모바일의 상세 링크는 업무 목록 다음에 둔다.
- 사진·전화번호는 사용자 결정에 따라 데이터부터 제외했다. 연락은 이메일과 GitHub만 제공한다. 원본 PDF에는 별도 개인정보가 있으므로 자동으로 공개하지 않는다.

## 원본 갱신

`data/generalResume.json`은 이웃 resume 저장소의 `getResumeVariant('general')` 결과를 공개 필드만 선택해 내보낸 정적 데이터다. 회사별 제출본이나 raw commonResume는 사용하지 않는다.

```bash
node scripts/export-resume-content.mjs
```

원본 위치가 다르면 데이터 디렉터리를 인수로 전달한다. 내보내기는 이력서 원본을 수정하지 않는다. 새 프로젝트가 추가되면 스크립트의 이름-라우트 매핑을 먼저 보완해야 한다. 실제 배포 빌드는 이웃 저장소에 접근하지 않는다.

## 검증 범위

- 기본 이력서의 공개 내용 일치와 기존 프로젝트 상세 매핑
- 공개 연락처 제한, 만료·손상된 복귀 상태 처리
- 경력 목차, 상세 진입/브라우저 뒤로가기, 자기소개 펼치기
- 모바일 줄바꿈·가로 넘침, 로고 폴백과 모션 감소
- 기존 파일의 해시가 작업 전 상태와 동일한지 확인
